YF Framework Documentation

A lightweight, high-performance, modular UI framework built from scratch with modern CSS and object-oriented JavaScript.

Production Files

For production use, include the compiled and minified bundle files in your project:

  • yf.min.css — Contains all core layout styles, utility classes, and component designs.
  • yf.min.js — Contains the core selector engine (yf) and all object-oriented component classes.

Essential JavaScript Hooks

Make sure to use these essential container and hook classes in your HTML so the object-oriented JavaScript components can automatically detect and initialize correctly:

Class / Hook Component Purpose
yf-accordion-group Parent wrapper container required for accordion JavaScript binding.
yf-sidebar Off-canvas sidebar element container.
yf-sidebar-close Triggers sidebar closure when clicked.
yf-sidebar-overlay Background backdrop overlay for sidebars.
yf-modal Popup dialog container component.
yf-modal-close Hook for elements/buttons that close active modals.
yf-modal-backdrop Backdrop area for clicking outside to dismiss modals.
yf-toast-container Dynamic container wrapper where toast notifications render.
yf-toast-close Close button trigger inside individual toast alerts.

Quick Start Code

Include your compiled CSS files in your <head> and your framework script bundle at the bottom of your <body>: 

<head>
  <link rel="stylesheet" href="css/yf.min.css">
  <link rel="stylesheet" href="css/theme.css"> <!-- Optional custom overrides -->
</head>
<body>
  <!-- Your HTML components here -->
  <script src="js/yf.min.js"></script>
</body>

Accordion

The accordion uses JavaScript to toggle the active class and control the panel's maximum height.

YF CSS is a lightweight responsive CSS framework using the yf- prefix.

Yes. JavaScript controls the active state and panel height.

<button class="yf-accordion" type="button">

  <span>
    Question
  </span>

  <span class="yf-accordion-icon">
    +
  </span>

</button>

<div class="yf-accordion-panel">

  <p>
    Answer
  </p>

</div>

JavaScript

const acc =
  document.getElementsByClassName("yf-accordion");

for (let i = 0; i < acc.length; i++) {

  acc[i].addEventListener("click", function() {

    this.classList.toggle("active");

    const panel = this.nextElementSibling;

    if (panel.style.maxHeight) {
      panel.style.maxHeight = null;
    } else {
      panel.style.maxHeight =
        panel.scrollHeight + "px";
    }

  });

}

YF CSS uses mobile-first responsive breakpoints. Base classes apply to all screen sizes, while breakpoint classes override them at the specified width.

Responsive element 
.yf-d-block
.yf-d-md-flex
.yf-d-lg-grid

Breakpoints

sm = 576px
md = 768px
lg = 992px
xl = 1200px

Responsive Naming

Responsive utilities generally follow this pattern:

.yf-{utility}-{breakpoint}-{value}

For example:

.yf-text-md-center
.yf-flex-lg-row
.yf-gap-xl-4
.yf-w-md-50
.yf-overflow-lg-auto

YF JavaScript Framework

YF includes a lightweight, chainable core selector engine (yf) inspired by jQuery, paired with fully object-oriented component classes. It bridges the gap between clean functional DOM manipulation and robust class-based architecture.

Core Capabilities

The yf() selector automatically normalizes CSS selectors, element nodes, NodeLists, and arrays into a unified collection. It allows you to:

  • Manage Classes: Instantly add, remove, toggle, or check CSS classes (.addClass(), .removeClass(), .toggleClass()).
  • Control Visibility: Show, hide, or toggle element display states dynamically (.show(), .hide(), .toggle()).
  • Read & Write Content: Get or set inner HTML, text content, and form input values (.html(), .text(), .val()).
  • Manage Attributes: Read, set, or remove any custom or native HTML attributes (.attr(), .removeAttr()).
  • Event Handling: Attach and remove cross-element event listeners cleanly (.on(), .off()).

Quick Usage

yf(".element").hide();
yf("#button").on("click", () => {
  console.log("Clicked!");
});
yf(".box").addClass("active");
yf("input#email").val("user@example.com");

DOM Ready Helper

yf_ready(() => {
  console.log("DOM is fully loaded and ready");
});

YF Toast Component

The toast notification manager creates, injects, and displays alerts programmatically via static method calls or declaratively through HTML attributes.

Under the hood, `YFToast` dynamically creates a container wrapper (`.yf-toast-container`) on the fly if one doesn't exist, appends it to the ``, renders inner HTML templates, handles auto-dismiss timers, and triggers exit animations (`.is-removing`) before purging elements from the DOM. 

YFToast.show({
  title: "Success!",
  message: "Your changes have been saved.",
  type: "success", // success, warning, danger, info
  duration: 4000
});

YFSidebar Class

Sidebars are managed through the YFSidebar class. It handles off-canvas slide-in mechanics by toggling the .is-open class on sidebars and the .is-visible class on background overlays.

It uses a internal WeakMap cache to prevent duplicate event listener bindings and automatically maps elements with data-yf-target attributes to open or close smoothly. 

// Manual instantiation or configuration override
new YFSidebar("#mainSidebar", {
  closeOnOverlayClick: true
});

YFModal Class

The modal component manages dynamic visibility (toggling opacity, visibility, and pointer-events), background scroll-locking (document.body.style.overflow = "hidden"), backdrop click closures, and global ESC key exit events. 

// Manual instantiation
new YFModal("#demoModal", {
  closeOnBackdrop: true,
  closeOnEsc: true
});

YFAccordion Class

Accordions require a parent wrapper with .yf-accordion-group. Instead of hardcoded heights, the accordion dynamically computes the exact pixel height of hidden content using panel.scrollHeight, animating the maxHieght property for fluid collapsible panels while toggling the .active class. 

// Initialize with custom options
new YFAccordion("#faqAccordion", {
  showFirst: false
});
